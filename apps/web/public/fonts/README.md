# Fuentes

Todas las fuentes se sirven como archivos locales desde este directorio: el
render en servidor las necesita en disco y una CDN introduciría un fallo de red
en el camino crítico del PNG.

| Familia | Archivos | Licencia | Uso comercial |
| --- | --- | --- | --- |
| Amiri | `Amiri-400.ttf`, `Amiri-700.ttf` | SIL Open Font License 1.1 | Sí |
| Playfair Display | `PlayfairDisplay-{400,500,700}.ttf` | SIL Open Font License 1.1 | Sí |
| Inter | `Inter-{400,500,600}.ttf` | SIL Open Font License 1.1 | Sí |

Origen: Google Fonts (`fonts.gstatic.com`), archivos TTF sin subsetear para que
el árabe conserve el juego completo de glifos y ligaduras.

La OFL permite el uso comercial y la incrustación; exige conservar el aviso de
licencia y no vender las fuentes por separado. Antes de añadir cualquier familia
nueva, comprobar su licencia y anotarla en esta tabla.
